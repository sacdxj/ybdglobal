# Naming, Domain, And Trademark System

## Naming Philosophy

The brand name should not be a keyword container.

The project should avoid names built directly from:

- Dirt.
- Volt.
- Trail.
- Ride.
- Electric.
- Bike.
- Moto.
- E-bike.

These words can remain in SEO, page titles, category descriptors, and product copy. They should
not drive the master brand unless availability and strategy make an exception worthwhile.

## Desired Name Type

The preferred name is:

```text
Distinctive, pronounceable, short, brandable, category-flexible, and .com-oriented.
```

The name should be able to carry:

- Electric dirt bikes.
- Kids bikes.
- Helmets.
- Gloves.
- Apparel.
- Batteries.
- Chargers.
- Parts.
- Service.
- Reviews.
- Dealer programs.
- YouTube content.
- Buying tools.

## Name Length Rules

Preferred:

- 7-10 letters.
- 2-3 syllables.
- Easy to say on a phone call.
- Easy to spell after hearing once.

Allowed:

- 5-6 letters if very strong.
- 11-12 letters if exceptionally memorable.

Avoid:

- More than 12 letters.
- Acronyms.
- Random consonant clusters.
- Hyphens.
- Numbers.
- Intentional misspellings that create confusion.

## Sound Rules

Prefer names with:

- Open vowels.
- Strong but not aggressive consonants.
- Natural American pronunciation.
- A premium outdoor or trusted advisor feel.

Avoid names that:

- Sound like cheap dropshipping brands.
- Sound like toys.
- Sound like dangerous speed-only brands.
- Sound too close to existing powersports brands.
- Are hard to pronounce for American buyers.

## Semantic Directions

Use abstract or semi-abstract cues from:

- Trust.
- Direction.
- Terrain.
- Clarity.
- Guidance.
- Readiness.
- Confidence.
- Control.
- Discovery.
- Outdoor movement.
- Engineering reliability.

Do not make the name too literal.

## First-Pass Filters

Reject any name that:

- Contains direct category terms unless explicitly approved.
- Is hard to pronounce.
- Has unclear spelling.
- Sounds too similar to a known bike, EV, outdoor, or powersports brand.
- Feels like a temporary Amazon private-label name.
- Has obvious negative meaning in English.
- Has obvious negative meaning in major languages after screening.
- Cannot plausibly become a `.com`.

## Domain Rules

Priority order:

1. Exact `.com`.
2. `get[name].com` only if exact `.com` is unavailable and the brand is very strong.
3. `ride[name].com`, `shop[name].com`, or `[name]bikes.com` only as temporary launch bridges.
4. Avoid non-.com domains for the primary consumer brand.

Do not use:

- `.bike`.
- `.shop`.
- `.co`.
- `.io`.
- Hyphenated domains.
- Domains with numbers.
- Domains that include competitor names.

## Trademark Screening Rules

This is not legal advice. A trademark attorney should review the final shortlist.

Initial screening should check:

- USPTO exact match.
- USPTO similar sound.
- USPTO similar spelling.
- Related classes for bikes, vehicles, apparel, accessories, retail, media, and ecommerce.
- Common-law usage through Google search.
- Social handles.
- Amazon and marketplace brand conflicts.
- App store conflicts if tools or apps are planned.

## Name Scorecard

Score each candidate from 1-5.

| Criterion | Score |
|---|---:|
| Pronounceable by US buyer | 1-5 |
| Easy to spell after hearing | 1-5 |
| Distinctive | 1-5 |
| Premium enough for high-ticket products | 1-5 |
| Flexible beyond bikes | 1-5 |
| Fits confidence/advisor positioning | 1-5 |
| Does not sound unsafe or toy-like | 1-5 |
| Exact `.com` available | 1-5 |
| Low trademark risk | 1-5 |
| Clean search results | 1-5 |

Recommended threshold:

```text
40+ = shortlist
35-39 = reserve
Below 35 = reject
```

## Final Shortlist Requirements

Before choosing a name, the shortlist should include:

- 20 strong candidates.
- Domain status.
- USPTO preliminary status.
- Search cleanliness notes.
- Pronunciation notes.
- Possible tagline.
- Brand story fit.
- Visual identity potential.
- Expansion risk.

## Naming Deliverable

The final naming package should include:

- Recommended top 3.
- Backup top 10.
- Rejected but interesting list.
- Domain acquisition notes.
- Trademark risk notes.
- Final naming rationale.
- Recommended public brand descriptor.

Example descriptor:

```text
[Brand Name] helps riders choose electric dirt bikes with confidence.
```
