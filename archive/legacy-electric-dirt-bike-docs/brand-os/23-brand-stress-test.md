# Brand Stress Test

## Purpose

The final brand name should not win because it sounds good in isolation. It should win because it
works across the full brand system.

This test compares:

```text
Ovkera
Ovkara
Ovkaro
```

against the real environments where the brand must live.

## Core Strategy Test

The brand is not:

```text
We sell electric dirt bikes.
```

The brand is:

```text
We help riders buy with confidence.
```

Therefore the winning name should feel like:

- Guide.
- Navigator.
- Trust.
- Clarity.
- Confidence.
- Decision support.
- Ownership support.

It should not primarily feel like:

- Racer.
- Garage.
- Extreme sports.
- Lifestyle apparel.
- Toy brand.
- Affiliate blog.

## Candidate Hypotheses

### Ovkera

Best hypothesis:

```

### Ovkara

### Ovkaro

```

## Pass Criteria

A name should only become final if it scores:

- 8/10 or higher on Brand DNA.
- 8/10 or higher on Guide / Navigator fit.
- 7/10 or higher on recall.
- 7/10 or higher on pronunciation.
- 8/10 or higher on visual identity.
- No severe `.com`, USPTO, common-law, social, or negative-meaning blocker.

## Decision Override: Conflict Scan

The visual and strategy stress test ranked `Ovkera` first before the deeper conflict scan.

After reviewing the established `Vokèra / Vokera` heating brand, `Ovkera` should not remain the
master brand recommendation.

Updated decision:

```text
Ovkara > Ovkaro > Avkoro
Reject: Ovkera
```

Why:

- `Ovkera` is visually too close to `Vokèra / Vokera`.
- `Ovkara` preserves the naming-family warmth but separates better from the known brand conflict.
- `Ovkaro` remains useful but leans more mechanical/powersports.
- `Avkoro` is a safer backup because the opening letter pattern is more distinct.

Use `25-ovkara-final-clearance-pack.md` as the current decision-stage document.
