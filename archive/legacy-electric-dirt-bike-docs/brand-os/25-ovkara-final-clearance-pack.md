# Ovkara Final Clearance Pack V1

## Purpose

This document records the decision-stage screen for `Ovkara`.

This is not a legal opinion. It is an internal brand-clearance pack used before registering the
domain, commissioning visual identity work, filing a trademark, or switching the website from
private review to public launch.

## Candidate

```text
Ovkara
```

Working pronunciation:

```text
ov-KAR-ah
```

Working role:

```text
Master brand candidate for the Electric Dirt Bike Decision Brand.
```

Brand sentence:

```text
Ovkara helps riders choose electric dirt bikes with confidence.
```

## Why Ovkara Advanced

`Ovkara` advanced because it keeps the strength of the Ovkaro naming family while avoiding the
most serious `Ovkera` conflict risk.

It fits the Brand OS because:

- It is short, invented, and category-flexible.
- It can stretch from decision content into bikes, helmets, apparel, batteries, chargers, and
  ownership support.
- It has warmer consumer-brand energy than `Ovkaro`.
- It is easier to build into a lifestyle and community brand than `Ovkera`.
- It works naturally in `Ovkara Guide`, `Ovkara Fit Check`, `Ovkara Compare`, `Ovkara Support`, and
  `Ovkara Garage`.

## Conflict Scan Summary

### Exact-Match Screen

First-pass public web search did not surface an obvious mature exact-match `Ovkara` brand.

Decision:

```text
Exact-match risk appears low in the first pass.
```

### Near-Spelling / Near-Sound Screen

The main near-name risks to review are:

| Name | Risk type | Notes |
|---|---|---|
| Ovkaro | Defensive family name | Keep as defensive registration if budget allows |
| Ovkera | Rejected family name | Too close to `Vokèra / Vokera` |
| Avkoro | Backup family name | More separated visually; useful reserve |
| Ovara | Near spelling | Needs trademark-class review |
| Ukara | Near sound / near spelling | Needs search review |
| Orkara / Orkaria / Orkavia | Nearby coined forms | Needs search review if surfaced in trademark databases |
| Ovčara / Ovcara | Negative semantic adjacency | Not a brand conflict, but a serious historical association in Balkan/Croatian contexts |

### Vokèra / Vokera Comparison

`Ovkara` is materially safer than `Ovkera`.

Visual comparison:

```text
VOKERA
OVKERA  -> rejected / high visual conflict
OVKARA  -> more separated, safer
```

Reason:

- `Ovkara` changes the center vowel pattern.
- `Ovkara` does not read as a direct rearrangement of `Vokera` as strongly as `Ovkera`.
- `Ovkara` keeps the warm `kara` ending, which creates a different consumer-brand feel.

Decision:

```text
Vokèra / Vokera does not reject Ovkara in this first-pass screen.
```

### Negative-Meaning Screen

The biggest non-trademark watch item is `Ovčara / Ovcara`, a place name associated with the
Vukovar / Ovčara massacre.

This is not the same word as `Ovkara`, but search engines and non-accented spelling can surface
adjacent results.

Decision:

```text
Not an automatic reject, but it must be reviewed before final public approval.
```

Mitigation:

- Prefer `Ovkara` pronunciation as `ov-KAR-ah`, not `ohv-CHAR-ah`.
- Avoid visual styling that makes `k` look like `c`.
- Avoid European/Balkan visual references.
- Run a U.S. pronunciation and negative-association test with at least 10 people before launch.
