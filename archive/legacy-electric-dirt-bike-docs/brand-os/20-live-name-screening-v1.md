# Live Name Screening V1

## Scope

This is a preliminary live web screening for the Naming Sprint V1 shortlist. It is not legal
advice and does not replace a trademark attorney, registrar checkout, WHOIS/RDAP review, USPTO
clearance, or common-law search.

Date: 2026-08-01

## Screening Method

Checked, where available:

- Exact `.com` web presence.
- Obvious existing brand use.
- Obvious trademark records surfaced through web search.
- Category proximity to vehicles, outdoor, ecommerce, software, retail, and consumer products.
- Search-result cleanliness.

## Important Limitations

- A search result not appearing is not proof of availability.
- Marketplace domain listings do not guarantee transfer until checkout/escrow is complete.
- USPTO and international trademark results require professional similarity analysis.
- Similar-sounding marks can still create risk even when exact marks appear unrelated.
