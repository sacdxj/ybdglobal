# Evidence Approval Matrix

## Purpose

This matrix controls what can be published as a fact. The site is a decision brand, so each
claim must help the buyer make a safer decision instead of filling a page with unsupported
marketing.

## Approval Levels

| Level | Meaning | Public use |
|---|---|---|
| L0 | Draft or placeholder idea | Do not publish as fact |
| L1 | Source exists but owner has not approved wording | Use only conservative confirmation language |
| L2 | Owner-approved factual claim | Can publish on relevant pages |
| L3 | Owner + legal/safety/technical reviewed | Required for high-risk claims |

## Required Approval by Claim Type

| Claim type | Minimum level | Required owner | Evidence required |
|---|---:|---|---|
| Brand name, domain, promise | L2 | Brand owner | Final brand decision and domain record |
| Logo and visual identity | L2 | Brand owner | Approved identity direction and usage test |
| Product price and availability | L2 | Merchandising | Current SKU price, inventory, update date |
| Shipping coverage and cost | L2 | Operations | Delivery policy, carrier/cost rules, exclusions |
| Warranty and returns | L3 | Legal/Warranty | Approved terms, exclusions, claim workflow |
| Street-legal or dual-sport wording | L3 | Legal/Product | VIN/MSO/title/certification/equipment/state workflow |
| Youth fit and safety | L3 | Product/Youth Safety | Fit table, manual, supervision and gear guidance |
| Speed, range, motor, battery | L3 | Technical/Battery | Test method, definitions, reviewer approval |
| Parts and repair | L2 | Support/Technical | Parts catalog, manuals, repair workflow |
| Financing | L3 | Finance/Legal | Provider terms, APR/fees/disclosures/refund workflow |
| Competitor comparisons | L2 | Editorial/Product | Current official source, review date, comparison method |

## Current State

All internal placeholders have been removed from public-facing content. The site remains in
private-review mode because the final brand, policies, product evidence, legal/safety reviews,
and official competitor source updates still require approval.

## Rule

When evidence is missing, publish a decision path or support-confirmation path. Do not publish
the missing claim as if it were approved.
