## Buyer situation

A buyer wanted a USB-C hub that could carry their brand identity while keeping port claims, packaging text and sample approval under control. The project needed to separate visible branding from functional claims such as display output, data transfer and charging pass-through.

## Customization scope

| Area | Project requirement |
| --- | --- |
| Hub reference | Confirm host compatibility, port mix, housing finish and intended simultaneous use |
| Logo method | Review printing, laser marking, label or package-only branding based on housing material and available process |
| Packaging | Confirm sleeve, insert, barcode, SKU label and carton mark requirements |
| Claim control | Verify port functions, power pass-through and display behavior against the selected hub sample |

## Approval workflow

The project should move through a visual logo review, functional sample review and packed sample review. If the buyer changes the port mix, housing, chip solution or package claim language, the revision should be rechecked before final quotation.

## RFQ inputs to prepare

Send the desired hub ports, host device type, logo file, preferred logo size and position, package style, destination market, sample requirement and any evidence needed for the sales channel.
