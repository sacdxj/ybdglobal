# RFQ Customer Journey

## Entry paths

- Product search → product family or product page
- Specification search → supported specification page
- Manufacturer/OEM search → product-specific procurement landing
- Buyer-type search → buyer solution
- Educational search → guide → relevant commercial parent

## Qualification sequence

1. Product family and connector/port combination
2. Required power, protocol, bandwidth or display output
3. Length, jacket, housing, color and materials
4. Logo, packaging, barcode and private-label requirements
5. Quantity and forecast
6. Destination market and certification requirements
7. Sample requirement and target delivery date
8. Buyer name, company, email and country

## Conversion behavior

- Preserve configuration selections in the RFQ URL or form state.
- Never discard a configured requirement when moving to the contact step.
- Show which fields need sales/engineering confirmation.
- Separate sample requests from mass-production RFQs while keeping the same specification context.
- Provide a success state and an expected next-step statement only after a real receiving workflow exists.

## Analytics events

- configurator start
- step answer
- result view
- RFQ CTA click
- sample CTA click
- form start
- form validation error
- form submit success/failure

Do not enable conversion analytics until privacy, consent and data destinations are approved.
